- 2026-11-14: The owner merges whatever pull request is open, so do not stack pull requests on one another; open the next one from the default branch after the previous one merges.
- 2026-11-14: A cross-project conversation is presented to the owner once it closes (at most three rounds); the owner decides before anyone acts on an agreement.
